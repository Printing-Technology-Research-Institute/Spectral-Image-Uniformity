# 光譜影像均勻度演算軟體

現場操作說明，對應操作手冊的動態分析介面與驗證介面。動態分析連接 Specim FX17，對輸送帶上的樣本做黑白校正、形變校正，並即時計算均勻度與電阻值。驗證介面用來查看這些結果，以及 CAE 均勻度與三點熱均勻度的關聯。

此版程式邏輯為「A 版＿逐批完整校正版（Queue 512）」。取像期間每 20 行做完整黑白校正。每次按「開始」樣本編號從 `FX17_0001` 重新計數；沒有完整通過的片段不占用編號。

請用根目錄的啟動器開啟動態分析，不要直接雙擊 `app.py`。

## 1. 放到現場電腦

1. 將整個資料夾複製到現場電腦的本機 SSD。放在 C 槽或 D 槽皆可，資料夾之後可以再搬移。
2. 現場電腦必須保留當時已驗證的 Python 3.9 環境。啟動器預設依序尋找：
   - 環境變數 `FX17_PYTHON` 指向的 `python.exe`
   - `D:\Python39\python.exe`
   - `C:\Python39\python.exe`
   - `%LOCALAPPDATA%\Programs\Python\Python39\python.exe`
3. Python 環境本身不要任意搬移。GenICam／GenTL 在凍結或搬移的 Python runtime 中會卡在建立資料流，因此此版使用現場已安裝、可正常連線的 Python。
4. NVIDIA 驅動與相機、網路卡的系統驅動仍須由現場電腦提供。

若 Python 不在上述位置，先設定環境變數 `FX17_PYTHON` 指向正確的 `python.exe`，再啟動。

## 2. 啟動動態分析

雙擊根目錄的 `啟動_光譜影像均勻度演算軟體.cmd`。

啟動器會檢查 PySide6、NumPy、OpenCV、PyTorch、OpenPyXL、Harvester、GenICam，並把相機 runtime 同步到 LocalAppData 的純英數路徑。原生訊息寫入 `動態分析模組/qt_demo/runtime_console.log`，不會顯示黑色命令列視窗。

視窗標題為「光譜影像均勻度動態分析軟體」。小螢幕與 Windows 顯示縮放下，熱圖會在可用區域內完整等比例顯示。

## 3. 動態分析畫面

| 代號 | 位置 | 內容 |
| --- | --- | --- |
| A | 相機控制區 | 連線狀態、相機序號、曝光時間（ms） |
| B | 黑白校正區 | 白校正檔、黑校正檔，「拍攝黑／白校正」、「選擇黑／白校正檔」 |
| C | 形變校正區 | 推掃取像參數校正與目前 line rate |
| D | 檢測分析區 | 分析結果儲存路徑、「選擇儲存路徑」、「開始」、「停止」 |
| E | DETECTOR 顯示區 | 上方「光譜 × 空間」，最新一幀與 DN 色階 |
| F | 即時偽色影像顯示區 | 按下開始後的輸送帶畫面 |
| G | 均勻度熱圖顯示區 | 右下分析結果，該樣本的殘差熱圖 |
| H | 均勻度結果 | 底部均勻度（%） |
| I | 電阻值結果 | 底部電阻值（Ω） |

即時分析的 direct 與 fallback 遮罩都只保留最大的 8-connected component。材料分割使用全波段平均反射率最亮的 10% 像素，以其平均光譜作為光譜角參考。動態檢測目前不套用反光遮罩；CAE 均勻度與電阻值都使用分割後的完整材料像素。

電阻模型為 2026-10-19 版：第一批 30 件加第三批 37 件，共 67 件，排除第三批 38 號；不含厚度，五折交叉驗證選出 5 個成分後以全部 67 件重訓。該模型訓練時曾用反光遮罩排除受反光干擾的像素。若日後拍攝仍有反光，推論看到的像素會和當時的訓練資料不同。

## 4. 建議作業順序

每次開機、換相機，或改過曝光時間之後：

1. 啟動程式，確認相機控制區顯示已連線與相機序號。
2. 設定曝光時間，並維持照明不變。
3. 拍攝或載入同一組黑／白校正檔。
4. 開啟輸送帶並讓速度穩定，再做形變校正。
5. 選擇分析結果儲存路徑。
6. 按「開始」，放入待測樣本。
7. 測完按「停止」，等畫面出現 Excel 已保存。
8. 需要對照熱均勻度時，再用驗證介面打開這次的樣本資料夾。

相機序號變更或曝光時間變更時，舊的形變校正會失效。曝光與照明在同一組黑白校正期間必須保持不變。

## 5. 曝光調整

在相機控制區調整曝光時間，單位是 ms。改完曝光後，重新做黑白校正與形變校正。

## 6. 黑白校正

1. 先把白板放在鏡頭下方，確認 DETECTOR 裡可以清楚看到白板。
2. 按「拍攝黑／白校正」。
3. 使用預設檔名，或輸入自訂的校正檔名。程式會依相機序號、曝光與時間給建議名稱，黑檔與白檔自動配對。
4. 按「存檔」。檔名已存在時，程式會先詢問是否覆寫。
5. 出現「準備黑校正」後按 OK。程式會自動關閉快門拍攝黑校正。
6. 出現「準備白校正」後，確認白板仍在、照明與曝光不變，再按 OK。
7. 上方訊息出現黑／白校正完成後，新的校正檔才會啟用。

若白校正對話框按了取消，黑校正檔已儲存，但配對尚未完成，不能拿來檢測。

沿用既有校正檔時，按「選擇黑／白校正檔」，分別指定同一曝光、同一台相機拍下的黑檔與白檔。載入成功後，上方會顯示校正檔已載入。配對無效時，目前使用中的校正檔維持不變。

## 7. 形變校正

這一步把 FX17 的 line rate 調到與目前輸送帶速度相符，避免影像在掃描方向被拉長或壓扁。

1. 開啟輸送帶，先讓它達到穩定速度。讀取 line rate 之前不要放入標準件。
2. 按「開始校正」。
3. 出現「準備推掃取像參數校正」後按 OK。
4. 狀態列顯示目前 line rate 後，把印有黑色圓形標準件的平整紙張放上輸送帶，讓圓形完整進入再完整離開相機視野。
5. 出現「推掃取像參數校正完成」後按 OK。對話框會列出偵測寬度、高度、H/W，以及原 line rate 與新 line rate。
6. 左側狀態變成「已套用 line rate … Hz」，即完成形變校正。

校正進行中按鈕會變成「取消校正」。影像不完整、太短或圓形辨識失敗時，依狀態列重新放入一次。

若計算出的 line rate 超過目前曝光下的上限，程式不會改曝光，也不會寫入 line rate。請降低曝光後重做黑白校正與這一步；影像變暗時增加照明，或改為降低輸送帶速度。若低於下限，請提高輸送帶速度後重新校正。

## 8. 檢測分析

1. 按「選擇儲存路徑」。
2. 選好分析結果要存放的資料夾。
3. 按「選擇資料夾」。
4. 按「開始」。程式建立這一次的檢測紀錄資料夾，樣本編號從 `FX17_0001` 起算。
5. 放入樣本。樣本要完整通過視野後才開始分析。
6. 分析完會立刻更新殘差熱圖、均勻度與電阻值。下一件可在前一件尚未存完時繼續通過；存檔完成前不要再按一次「開始」。
7. 這一批測完後按「停止」。若還有樣本在分析或存檔，畫面會顯示正在完成。
8. 看到「檢測分析已停止；Excel已保存」之後，才能開始下一個工作階段。

上一個工作階段仍有樣本等待分析與存檔時，再按「開始」只會提示等待。

## 9. 分析結果紀錄

每次按「開始」都會在所選路徑下建立一個資料夾，名稱類似 `檢測紀錄_20260818_092000`。

| 位置 | 內容 |
| --- | --- |
| `檢測紀錄_＜時間＞.xlsx` | 「檢測紀錄」列出每件樣本的時間、樣本 ID、均勻度、電阻值、曝光、line rate、校正檔與狀態；「工作階段資訊」記錄起迄時間與校正檔路徑 |
| `校正檔/` | 這一輪使用的黑校正檔與白校正檔副本 |
| `FX17_0001_＜拍攝時間＞/` | 該件樣本的資料夾。名稱是樣本編號加拍攝時間 |

每個樣本資料夾內有未校正與校正後的 HDR／RAW，以及殘差熱圖 PNG。Excel 裡的 HDR 與熱圖路徑是相對這個新資料夾名稱的路徑。

Excel 每一列在樣本剛拍完時先記為「等待分析」，分析成功後改為「完成」。失敗時狀態為「分析失敗」，備註欄有原因。

取像診斷紀錄在資料夾內的 `acquisition_logs`。每次現場測試後，請一併備份該次的檢測紀錄資料夾與 `acquisition_logs`。

## 10. 驗證介面

驗證程式是根目錄的 `驗證介面_獨立版_20261008.exe`。雙擊開啟，不經過 Python 啟動器。

畫面有兩個頁面，左側是功能選單，其旁是樣本選擇區。

| 頁面 | 右側內容 |
| --- | --- |
| 關聯性分析 | 關聯性結果、CAE 均勻度與三點熱均勻度散佈圖、換算熱均勻度 |
| 單件樣本資訊 | 樣本資訊、CAE 殘差熱圖與均勻度、熱成像與熱均勻度 |

### 計算關聯性與換算熱均勻度

1. 在樣本選擇區勾選要參加計算的樣本。
2. 按「計算關聯性並產生圖」。
3. 結果區顯示關聯性與留一換算誤差。
4. 散佈圖是所選樣本的 CAE 均勻度對三點熱均勻度。
5. 長條圖是留一換算熱均勻度對實際三點熱均勻度。

### 查看單件樣本

1. 打開樣本下拉選單，點選要看的樣本。
2. 滑鼠指在樣本選單上時，滾動滾輪可以快速切換。
3. 單件頁會顯示該件的 CAE 殘差熱圖、均勻度，以及熱成像與熱均勻度。

### 匯入動態分析拍過的樣本

1. 按「開啟樣本資料夾」。
2. 進到某一次的 `檢測紀錄_＜時間＞` 資料夾。
3. 點選要查看的那一個樣本資料夾，例如 `FX17_0001_＜拍攝時間＞`。
4. 按「選擇資料夾」。
5. 即可查看動態分析輸出的殘差熱圖、均勻度分數與電阻值。

## 11. 結束與備份

1. 確認沒有樣本還在分析，且動態分析已顯示 Excel 已保存。
2. 關閉動態分析與驗證介面。
3. 複製本次 `檢測紀錄_＜時間＞` 資料夾與 `acquisition_logs` 到備份位置。

校正檔與形變校正結果會留在程式設定中，下次啟動會沿用。換相機、改曝光、改輸送帶速度或改照明後，回到第 4 節重做對應校正。

## 12. 啟動失敗時要留的紀錄

請保留整個資料夾，並提供這三個檔案：

- 根目錄 `startup_error.log`
- 根目錄 `python_runtime_selection.log`
- `動態分析模組/qt_demo/runtime_console.log`

常見原因是找不到已驗證的 Python 3.9、套件缺失、相機未連線，或資料夾權限不足。資料夾可以換位置；不要改動現場那份 Python 3.9 環境。
