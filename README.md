# 光譜影像均勻度演算軟體

現場操作說明。本軟體連接 Specim FX17 線掃描相機，對輸送帶上的樣本做黑白校正、推掃取像參數校正，並即時計算均勻度與電阻值。

請用根目錄的啟動器開啟程式，不要直接雙擊 `app.py`。

## 1. 放到現場電腦

1. 將整個資料夾複製到現場電腦的本機 SSD。放在 C 槽或 D 槽皆可，資料夾之後可以再搬移。
2. 現場電腦必須保留當時已驗證的 Python 3.9 環境。啟動器預設依序尋找：
   - 環境變數 `FX17_PYTHON` 指向的 `python.exe`
   - `D:\Python39\python.exe`
   - `C:\Python39\python.exe`
   - `%LOCALAPPDATA%\Programs\Python\Python39\python.exe`
3. Python 環境本身不要任意搬移。實測確認 GenICam／GenTL 在凍結或搬移的 Python runtime 中會卡在建立資料流，因此此版刻意使用現場原本可正常連線的已安裝 Python，而不是免安裝封裝。
4. NVIDIA 驅動與相機、網路卡的系統驅動仍須由現場電腦提供。

若 Python 不在上述位置，先設定環境變數 `FX17_PYTHON` 指向正確的 `python.exe`，再啟動。

## 2. 啟動

雙擊根目錄的 `啟動_光譜影像均勻度演算軟體.cmd`。

啟動器會檢查 PySide6、NumPy、OpenCV、PyTorch、OpenPyXL、Harvester、GenICam，並把相機 runtime 同步到 LocalAppData 的純英數路徑。原生訊息寫入 `動態分析模組/qt_demo/runtime_console.log`，不會顯示黑色命令列視窗。

視窗標題為「光譜影像均勻度動態分析軟體」。2026-09-01 版已支援小螢幕與 Windows 顯示縮放；熱圖會在可用區域內完整等比例顯示。

## 3. 畫面

左側由上到下是四個操作區，右側是即時畫面與數值。

| 位置 | 內容 |
| --- | --- |
| 相機控制 | 連線狀態、相機序號、曝光時間（ms） |
| 黑白校正 | 目前白校正檔、黑校正檔，以及拍攝或選擇校正檔 |
| 推掃取像參數校正 | 目前 line rate 狀態，以及「開始校正」 |
| 檢測分析 | 分析結果儲存路徑、「選擇儲存路徑」、「開始」、「停止」 |
| 上方「光譜 × 空間」 | 最新一幀的光譜與空間影像，右側為 DN 色階 |
| 左下「即時偽色影像」 | 按下開始後的輸送帶即時畫面 |
| 右下「分析結果」 | 該樣本的均勻度熱圖 |
| 底部卡片 | 均勻度（%）與電阻值（Ω） |

即時分析的 direct 與 fallback 遮罩都只保留最大的 8-connected component。零星孤立像素不列入均勻度與電阻值。

## 4. 建議作業順序

每次開機、換相機，或改過曝光時間之後，依這個順序做一次：

1. 啟動程式，確認左側顯示「已連線」與相機序號。
2. 設定曝光時間，並維持照明不變。
3. 拍攝或載入同一組黑／白校正檔。
4. 讓輸送帶達到穩定速度，再做推掃取像參數校正。
5. 選擇分析結果儲存路徑。
6. 按「開始」，放入待測樣本。
7. 測完按「停止」，等畫面出現 Excel 已保存後再離開。

相機序號變更或曝光時間變更時，舊的推掃校正會失效，狀態列會要求重新校正。曝光與照明在同一組黑白校正期間必須保持不變。

## 5. 黑白校正

新相機或曝光時間改變後，先重新執行黑白校正。

### 現場拍攝

1. 按「拍攝黑／白校正」。
2. 在存檔對話框設定這一組校正檔的共用名稱。程式會依相機序號、曝光與時間給建議檔名，黑檔與白檔會自動配對。
3. 確認「準備黑校正」。程式會自動關閉快門並拍攝黑校正，此時不要放白參考板。
4. 黑校正完成後，依提示放置均勻白參考板。照明與曝光保持不變，再按確定開始白校正。
5. 上方訊息出現「黑／白校正完成」後，這一組校正才會啟用並寫入設定。

若白校正對話框按了取消，黑校正檔已儲存，但配對尚未完成，不能拿來檢測。檔名已存在時，程式會先詢問是否覆寫。

### 沿用既有校正檔

按「選擇黑／白校正檔」，分別指定同一曝光、同一台相機拍下的黑檔與白檔。載入成功後，上方會顯示校正檔已載入。若配對無效，目前使用中的校正檔不會被換成失敗的那一組。

## 6. 推掃取像參數校正

這一步用平整的圓形標準件，把 FX17 的 line rate 調到與目前輸送帶速度相符，避免影像在掃描方向被拉長或壓扁。recorded 來源不能做這項校正。

1. 先讓輸送帶達到穩定速度。讀取 line rate 之前不要放入標準件。
2. 按「開始校正」，閱讀「準備推掃取像參數校正」後按確定。
3. 狀態列顯示目前 line rate，並提示可以放入標準件後，把完整、平整的圓形標準件放上輸送帶，讓它完整進入再完整離開視野。
4. 標準件離開後，右下會顯示圓形偵測結果。程式計算新的 line rate、寫入相機並讀回。
5. 完成對話框會列出偵測寬度、高度、H/W，以及原 line rate 與新 line rate。左側狀態會變成「已套用 line rate … Hz」。

校正進行中按鈕會變成「取消校正」。影像不完整、太短或圓形辨識失敗時，狀態列會要求重新放入，不必整段重來。

若計算出的 line rate 超過相機在目前曝光下的上限，程式不會改曝光，也不會寫入 line rate。請降低曝光後重新做黑白校正與這一步；影像變暗時增加照明，或改為降低輸送帶速度。若低於下限，請提高輸送帶速度後重新校正。

## 7. 檢測分析

1. 按「選擇儲存路徑」，指定可寫入的資料夾。未選路徑就按開始時，程式會提示無法建立儲存資料夾。
2. 按「開始」。程式會建立這一次的工作階段資料夾，並開始取像。
3. 將樣本完整放上輸送帶。樣本進入視野後，左下標題會顯示樣本 ID；離開視野後開始分析。
4. 分析完成時，右下更新熱圖，底部更新均勻度與電阻值。下一個樣本可在前一個分析尚未結束時繼續通過，但不要在存檔完成前再按一次開始。
5. 這一批測完後按「停止」。若還有樣本在分析或存檔，畫面會顯示正在完成；全部完成後才會寫入 Excel，並顯示檔名。
6. 看到「檢測分析已停止；Excel已保存」之後，才能開始下一個工作階段。

上一個工作階段仍有樣本等待分析與存檔時，再按「開始」只會提示等待，不會開新的一輪。

## 8. 結果放在哪裡

每次按「開始」都會在所選路徑下建立一個資料夾，名稱類似 `檢測紀錄_20260818_092000`。

| 檔案 | 內容 |
| --- | --- |
| `檢測紀錄_＜時間＞.xlsx` | 「檢測紀錄」工作表列出每筆樣本的時間、均勻度、電阻值、曝光、line rate、校正檔與狀態；「工作階段資訊」記錄起迄時間與校正檔路徑 |
| `校正檔/` | 這一輪使用的黑校正檔與白校正檔副本 |
| `＜拍攝時間＞/` | 該樣本的未校正 HDR、校正後 HDR，以及殘差熱圖 PNG |

Excel 每一列在樣本剛拍完時先記為「等待分析」，分析成功後改為「完成」。失敗時狀態為「分析失敗」，備註欄有原因。

取像診斷紀錄在資料夾內的 `acquisition_logs`。每次現場測試後，請一併備份該次的分析工作階段資料夾與 `acquisition_logs`。

## 9. 結束與備份

1. 確認沒有樣本還在分析，且畫面已顯示 Excel 已保存。
2. 關閉程式視窗。
3. 複製本次 `檢測紀錄_＜時間＞` 資料夾與 `acquisition_logs` 到備份位置。

校正檔與推掃校正結果會留在程式設定中，下次啟動會沿用。換相機、改曝光、改輸送帶速度或改照明後，回到第 4 節重做對應校正。

## 10. 啟動失敗時要留的紀錄

請保留整個資料夾，並提供這三個檔案：

- 根目錄 `startup_error.log`
- 根目錄 `python_runtime_selection.log`
- `動態分析模組/qt_demo/runtime_console.log`

常見原因是找不到已驗證的 Python 3.9、套件缺失、相機未連線，或資料夾權限不足。資料夾可以換位置；不要改動現場那份 Python 3.9 環境。
